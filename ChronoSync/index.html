--- layout: tool_document redirect_path: /image-tools header_supertitle: Image Tools meta_title: ChronoSync — Temporal photo alignment meta_description: Align photos of the same location taken at different times using feature detection and compose them into a collage. og_title: ChronoSync — Temporal photo alignment icon_href: /image-tools/ChronoSync/assets/favicon.svg lang_mode: path webapp_application_category: PhotoApplication header_title: ChronoSync header_subtitle: Align and compare photos across time header_subtitle_id: subtitle intro_title: What is ChronoSync? intro_text: "ChronoSync aligns photographs of the same place taken at different times and composes them into a pixel-level collage. Each image is matched against a reference using ORB — a fast feature detector that describes edges and corners rather than colour or texture, making it robust to seasonal foliage changes, snow, or lighting shifts — with an automatic fallback to the stronger SIFT detector for hard pairs. Correspondences are filtered with a mutual cross-check and a warp per image (similarity or mild affine) is estimated with RANSAC over several hypotheses, kept only when it aligns better than leaving the image untouched; the result is cropped to the shared valid overlap so every panel shows exactly the same scene. Date labels are read from EXIF metadata when available. All processing runs in the browser via WebAssembly — nothing is uploaded." footer_credits_html: |
